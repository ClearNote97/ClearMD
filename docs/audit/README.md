# Audits

External reviews of the product, kept so their decisions can be traced. Each audit has a report for the owner
(in Spanish, by exception to ADR-0011) and the raw results of every round as JSON.

- [`2026-11-08-audit-boards.md`](./2026-11-08-audit-boards.md): the backend and frontend boards and the
  conciliator, on version 2.8.1.
