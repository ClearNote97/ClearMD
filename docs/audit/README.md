# Audits

External reviews of the product, kept so their decisions can be traced. Each audit has a report for the owner
(in Spanish, by exception to ADR-0011) and the raw results of every round as JSON.

- [`2026-11-08-audit-boards.md`](./2026-11-08-audit-boards.md): the backend and frontend boards and the
  conciliator, on version 2.8.1.
- [`2026-11-09-doubts-board-1.md`](./2026-11-09-doubts-board-1.md): the doubts board on the light
  installer, the windows' names and the unexpected error, convened while applying the audit.
- [`2026-11-09-audit-boards-v2.md`](./2026-11-09-audit-boards-v2.md): the second audit, on 2.10.0, with
  new agents and the first audit's lessons applied.
- [`2026-11-09-audit-boards-v3.md`](./2026-11-09-audit-boards-v3.md): the third audit, on 2.11.0, with
  five experts per board and three conciliators (truth, "Claridad es cariño", doctrine).
- [`2026-11-09-audit-boards-v4.md`](./2026-11-09-audit-boards-v4.md): the fourth audit, on 2.12.0, with
  the same method as the third and the owner's decisions passed to every auditor as constraints.
- [`2026-11-09-doubts-board-2.md`](./2026-11-09-doubts-board-2.md): the doubts board on readable escaping, the saved
  "full page" setting and the parts' opening line, convened while applying the fourth audit.
- [`2026-11-10-audit-boards-v5.md`](./2026-11-10-audit-boards-v5.md): the fifth audit, on 2.13.0, the last of the
  2.x line (at most five audits per major version).
