# Plan — Feature 006: CI and the executables

> The **how**. Criteria: [`spec.md`](./spec.md). Decisions: ADR-0008, ADR-0015, ADR-0026,
> ADR-0027, ADR-0028.

```
.github/workflows/
  ci.yml                    # lint + types (once); tests: Linux/Windows × Python 3.12/3.14
  release.yml               # build + check per system; publish on a v* tag
packaging/
  clearmd.spec              # PyInstaller: ClearMD (window, splash, icon) and clearmd (console)
  launch_gui.py, launch_cli.py
  check_executables.sh      # a real batch with the CLI; the window with --smoke
  package.sh                # the release files of one system
  notices.py                # THIRD-PARTY-NOTICES.txt from the installed packages' metadata
  RELEASE_NOTES.md          # EN/ES: how to open it, the SmartScreen warning, 100 % local
src/clearmd/frontend/assets/logo/
  clearmd.ico, splash.png   # generated by tests/gui/make_assets.py (ADR-0027)
```

## Steps

1. The build group (PyInstaller), the spec and the launchers; build and check on Linux in the
   container (a real batch, the window with `--smoke` under Xvfb).
2. The icon (.ico) and the splash from the asset script; `--smoke` and the splash closing in the
   GUI entry point.
3. CI on Linux and Windows; fix what only Windows shows.
4. The release workflow: build and check on both systems; publish on a tag.
5. Docs: README (download), ADR-0028, roadmap; the first release.
