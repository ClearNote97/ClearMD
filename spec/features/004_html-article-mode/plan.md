# Plan — Feature 004: HTML article mode

> The **how**. Criteria: [`spec.md`](./spec.md). Decisions: ADR-0006, ADR-0012, ADR-0023, ADR-0025.

## Architecture

```
src/clearmd/backend/
  schemas/
    formats.py              # + Strategy (FULL, ARTICLE)
    models.py               # PlannedConversion.strategy; the summary shows it
    notes.py                # + ARTICLE_NOT_FOUND (IMAGES_NOT_EXTRACTED reused)
  use_cases/planning.py     # html_strategy → each HTML item's strategy
  api/__init__.py           # plan_batch(html_strategy=...)
  services/
    conversion/
      xmltree.py            # moved from odt/ (shared by odt and html; stdlib only)
      registry.py           # for_format(format, strategy): (HTML, ARTICLE) → ArticleConverter
      html/                 # imported only inside the worker (trafilatura)
        __init__.py         # ArticleConverter: read → trafilatura XML → render, or the full page
        render.py           # trafilatura's XML → Markdown through markdown_out
    worker/protocol.py      # ConvertRequest.strategy
  frontend/cli/app.py       # --html full|article
```

## Steps

1. **The strategy through the pipeline** (no new converter yet): `Strategy`, `PlannedConversion.strategy`,
   `ConvertRequest.strategy`, `registry.for_format(format, strategy)`, `plan_batch(html_strategy=)`, the CLI
   flag and the setting, the summary's format column. Full stays the default; tests prove nothing else moved.
2. **`xmltree` moves** to `conversion/` (the architecture test keeps it standard library only); odt imports it.
3. **The converter**: `trafilatura.extract(html, output_format="xml", include_links=True,
   include_images=True, include_tables=True, include_formatting=True, with_metadata=True, favor_precision=…)`
   on the decoded text (read with `safe_files`, size-capped); `None` or an article under a minimum of text →
   the full page through markitdown + `ARTICLE_NOT_FOUND`.
4. **The renderer**: the subset of the spec, iterative, every text through `escape_text`, ClearMD's block
   lines marked, links through the shared link rules, images as placeholders; `neutralize` + `tidy`.
5. **Guarantee, acceptance, benchmark, close** as in features 002–003.

## Testing strategy

- Fixtures: a news-like page (menu, cookie banner, article with every construct, aside, footer), a page with no
  article (a form, a list of links), a hostile page (scripts, `javascript:` links, entities, raw HTML in
  text), all generated by `build_fixtures.py`.
- Unit: the renderer on trafilatura's XML written inline; the converter on the fixtures.
- Guarantee: the CommonMark check and a seeded fuzz over hostile HTML.
- Acceptance: `tests/acceptance/test_004_html_article_mode.py`, one test per criterion, with the network guard.
