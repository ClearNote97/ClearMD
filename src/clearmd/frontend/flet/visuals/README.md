# flet/visuals — The flet look

| Module | Role |
|---|---|
| `theme.py` | The shared palette as a Material theme: `ROLES`, ClearMD's colours and the slots that carry them. |
| `look.py` | Each kind of text (size, weight, colour) and each kind of button. |
| `images.py` | The assets folder, the file icons, the logo and the window's icon. |

Imports only `frontend.design`, `layout/` and flet; never `components/` or `views/`.
