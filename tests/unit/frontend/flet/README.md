# tests/unit/frontend/flet

The flet window (feature 018) where it meets flet itself: the adapter to flet's real page
(`window/flet_page.py`), the entry point (`app.py`) and the window's guards, on a stand-in page.
No flet program is started and nothing is downloaded; the window's behaviour is in
`tests/acceptance/test_018_flet_*`.
