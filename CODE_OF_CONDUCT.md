# Code of Conduct

ClearMD adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and patient, assume good faith, and keep discussions about the work. Harassment,
insults, personal attacks and sharing anyone's private information are not accepted, in issues, pull
requests or any other project space.

## Enforcement

The maintainer ([@ClearNote97](https://github.com/ClearNote97)) may edit or remove comments and block
participants who break these rules. To report a problem privately, use
[GitHub's private reporting](https://github.com/ClearNote97/ClearMD/security/advisories/new) and say it
is about conduct, or [report the content to GitHub](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
Every report is reviewed and kept confidential.
